# ModernAD Community

ModernAD Community is the successor of the original Modern_ActiveDirectory project.

The goal of this project is to continue the development of a lightweight and practical Active Directory health check and reporting solution for system administrators, consultants, and security professionals.

This repository starts from the latest stable version of Modern_ActiveDirectory and will progressively receive improvements, bug fixes, code cleanup, and new features.

Current status: Work in progress.

## Examples

[View Online Example ](https://dakhama-mehdi.github.io/BruteForce-Detector/Examples/ModernAD.html) 

## Objectives

- Active Directory health assessment
- Replication monitoring
- DNS validation
- SYSVOL and DFSR checks
- FSMO role verification
- Service validation
- Security and configuration checks
- HTML reporting

## Project Status

ModernAD Community is currently under active development.

Features, code structure, and reporting capabilities may evolve over time as the project is being modernized and improved.
